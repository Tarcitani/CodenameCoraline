## Architecture Checklist

When implementing a new boss or creature:

1. **Boss Bar** — Must have themed bossbar (not default Minecraft). Style in `client/bossbar/` implementing `ThemedBossBars.Style`, registered by entity translation key, texture at `textures/gui/boss_bar/<id>.png`.
2. **Achievements** — Add lore/milestone achievements.
3. **Bestiary** — Entry in bestiary system with description and unlock condition.
4. **GameTest Suite** — Tests for behavior in `build.gradle` run config.
5. **Validation** — Run `./gradlew build` and visual proof via `runClient`.
